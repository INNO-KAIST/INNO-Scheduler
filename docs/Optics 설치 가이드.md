# Weekly Optics Scheduler — 설치·운영 가이드

광학방 주간 스케줄 + 하드웨어 현황판. **Synthesis Scheduler와 같은 Firebase를 공유**하므로 설치가 훨씬 간단합니다 (Firebase 신규 생성 불필요, 명단·PIN 그대로 사용).

## 시스템 요약

| 구분 | 내용 |
|---|---|
| 시간표 | 월~일 전일제, 30분 단위(00–24시) 주간 캘린더. Batch 없음 |
| 투표 (월 00시~수 24시) | 1/2/3순위 **요일** 투표 (3개 다 채울 필요 없음). 월/화/수 12시 미투표자 Slack 멘션 리마인드 |
| 배정 (목 12시) | ①무당첨자 절대 우선 → ②순위 → ③투표 수 적은 사람 → ④시드 무작위. 요일 00-24시 통째 배정, Slack 자동 발표 |
| 발표 후 | **전원 자유 조율**: 클릭/드래그로 30분 단위 수정, 실시간 예약 탭(미니 스케줄+실시간 채팅), 희망순위 반투명 토글 |
| 캘린더 | ALLOWED_EMAIL_1@example.com 캘린더에 1분 간격 자동 동기화 |
| 변경사항 (Hardware Log) | LASER/Turret/SNSPD/Powermeter 현황판 + 변경 이력, 변경 시 Slack 자동 공지(1분 내) |
| 특이사항 (Remark) | 특이사항 자유 기록 (날짜·이름 자동). **최근 10개만 보관** — 새 기록 시 오래된 항목 자동 삭제 |

## 설치 (총 ~15분)

**1. 보안 규칙 교체 (2분)** — Firebase 콘솔 → Firestore → 규칙 탭 → `server/INNO_firestore.rules`(통합본) 전체 교체 → 게시. 합성 규칙에 광학 규칙이 추가된 단일 파일이며 합성 동작에는 영향 없음.

**2. 웹앱 배포 (2분)** — `Optics_scheduler.html`을 **기존 GitHub 저장소(INNO-Scheduler)에 추가 업로드** (Add file → Upload files). 주소: `https://inno-kaist.github.io/INNO-Scheduler/Optics_scheduler.html`
- 같은 도메인이라 Firebase 승인 도메인 추가 불필요. 별도 저장소를 원하면 새 repo에 올려도 되나, 그 경우 GAS 코드의 `appUrl`을 그 주소로 수정.

**3. 멤버 광학 활성화 (2분)** — 배포 주소 접속 → 관리자 계정으로 로그인(합성과 같은 PIN) → 관리자 탭 → 참여할 멤버마다 **"광학 활성화"** 클릭. (명단·PIN 공유, 광학/합성 활성은 별도 관리)

**4. GAS 봇 (10분)** — script.google.com → **새 프로젝트** (합성 봇과 별개) → `server/Optics_gas.txt` 전체 붙여넣기 → 저장
- 설정값(webhook·캘린더ID·앱주소·Slack 멘션 표)은 **이미 입력되어 있음**. 캘린더 계정 권한만 확인: GAS 실행 구글 계정이 ALLOWED_EMAIL_1@example.com 캘린더에 "일정 변경" 권한 필요 (그 계정 본인이면 자동 충족)
- 코드 상단 `SLACK_MENTION` 표 = 리마인드 멘션 명부 (합성 봇과 동일 형식). **채널 인원 변동 시 이 표도 갱신** (이름은 명단 표기와 정확히 일치해야 함)
- ⚙ 프로젝트 설정 → 시간대 **(GMT+09:00) Seoul** 확인
- `testSlack` 실행(권한 승인) → optics 채널 메시지 확인 → `testCalendar` 실행 → 캘린더 테스트 일정 확인 후 삭제
- `setup` 실행 → 트리거 2개 확인: `armDaily`(매일 9시대 — 월/화/수 12시 리마인드, 목 12시 발표 장전), `minuteJob`(1분 — 캘린더 동기화+하드웨어 알림)

## 운영 안내

- **조율 원칙**: 발표 직후부터 해당 주 일요일까지 전원 수정 가능. 수정 전 실시간 예약 탭에서 채팅 협의 권장. 미니 스케줄 수정도 즉시 전체 반영
- **미배정 요일**: 빈 상태로 시작 — 누구든 조율로 사용 가능. 무당첨자 배려 우선
- **변경사항(Hardware Log) 의무**: 부품 추가/제거/변경 시 즉시 현황판 수정. ND/Pinhole/Filter 등 기타 추가요소는 사용 후 해체·원상복구가 원칙 → 저장하면 변경 내용·일시(요일)·유저가 기록되고 Slack에 자동 공지
- **캘린더 직접 수정 금지**: 봇이 1분 내 원상복구함. 수정은 반드시 앱에서
- **특이사항(Remark) 활용**: 다음 사용자에게 알릴 특이사항(장비 이상, 임시 조치 등)은 특이사항 탭에 기록. 최근 10개만 유지되므로 영구 보존이 필요한 내용은 별도 문서에
- **멤버 변동**: 통합가이드 B절 + "광학 활성화" 토글 + 광학 GAS의 `SLACK_MENTION` 표 갱신 (월/화/수 12시 미투표자 멘션 리마인드에 사용)
- **주의**: 합성 스케줄러와 같은 명단을 쓰므로, 멤버 삭제·합성 활성 관리는 합성 관리자 탭에서

## 문제 해결

| 증상 | 해결 |
|---|---|
| 로그인 목록에 이름 없음 | 해당 멤버 "광학 활성화" 안 됨 → 관리자 탭에서 활성화 |
| 투표/수정 시 permission denied | 1번 규칙(통합본) 미게시, 또는 허용 시간 아님(정상), 또는 광학 비활성 |
| 발표/리마인드가 안 옴 | GAS 실행 메뉴 오류 확인, 트리거 2종 확인 후 setup 재실행. `previewRemind`로 즉시 발송 테스트 가능 |
| 리마인드에 특정 인원 멘션 안 됨 | GAS `SLACK_MENTION` 표에 그 이름이 없거나 명단 표기와 다름 → 표 갱신 |
| 캘린더 미반영 | GAS 계정의 캘린더 편집 권한 확인, `forceCalendarResync` 실행 |
| 하드웨어 변경 Slack 미공지 | minuteJob 트리거 확인. 공지는 변경 후 최대 1분 소요 |
