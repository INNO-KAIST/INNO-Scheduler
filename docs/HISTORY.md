# INNO Scheduler — 작업 이력

> 연구실 장비 주간 예약. Synthesis(합성 장비: 토큰 투표·추첨·실시간 예약)와 Optics(광학방: 요일 투표·배정·조율 채팅) 두 앱 + 시작 화면.
>
> 이 파일 하나에 이 앱의 작업 이력·교훈·문서 색인을 모았다. 자세한 근거는 색인의 문서(claude.ai 프로젝트 ‘유원정’)에 있다.

## 최근 작업
- **11-11 KOR / ENG 언어 전환 (두 앱 + 시작 화면)**: 우상단 토글. KOR = 기존 화면 그대로(전 탭·국면·역할 132개 화면 텍스트 동일 확인). ENG = 화면에 그려진 글자를 사전(600개 문구)으로 바꾸는 DOM 번역 층 — 앱 코드는 한국어 그대로 그리고 MutationObserver 가 즉시 바꾼다. 날짜·시간·순위 같은 조립 문구는 규칙으로 처리, 멤버 이름과 사용자 글(채팅·특이사항 본문, `translate="no"`)은 그대로. 규칙 탭은 영어판을 따로 씀(`renderRulesEn`). 확인창(confirm/alert)도 번역. 선택은 `localStorage.inno_lang` 에 저장돼 세 페이지가 공유, `?lang=en` 링크도 됨. 토글은 로그인 버튼(채운 하늘색)과 구분되도록 테두리 알약 + 지구 아이콘. 번역 블록은 두 앱에 글자 그대로 같다. **Slack 공지·구글 캘린더 제목·설명도 이름만 빼고 영어로 전환**(GAS 출력 층만 바꾸고 공유 코어는 그대로, 기존 캘린더 일정은 다음 동기화 때 제목·설명을 제자리 수정 — 광학은 이번에 '기존 일정 제목 갱신' 도 새로 생김). 하드웨어 알림은 웹앱이 한국어 고정 문구로 저장한 요약을 봇이 고정 문구만 영어로 바꿔 보냄(사용자가 쓴 값은 그대로). 새 한국어 문구를 앱에 넣으면 번역 사전에도 한 줄 추가할 것.
- **11-11 명단 관리를 «명단» 탭으로 통합 (두 앱 공통)**: 관리자로 로그인하면 «명단» 탭에서 바로 추가·편집(이름·Slack ID·합성/광학 참여·관리자)·삭제·되살리기·PIN/기기 초기화. 두 앱에 글자 그대로 같은 코드(`MEMBER_APP` 만 다름). 삭제는 '숨김'(hidden + 두 참여 끔 + 기기 해제 → 서버 권한도 사라짐, 과거 기록 이름 유지). 봇은 `members.slackId` 를 우선 쓰고 없으면 코드의 `SLACK_MENTION`(이름 기준)으로 폴백 — 웹에서 추가한 멤버도 리마인드에 태그됨. 관리자 탭의 옛 멤버 카드는 «명단 탭으로 가기» 버튼으로 대체. 규칙 변경 없음.
- **10-12 광학 캘린더가 시간대 배정을 무시하던 버그 수정 (+ 합성 엣지 1건)**: Optics GAS 가 시간대(분기) 도입 이전 코어로 남아 있어, 그날 '대표 당첨자'가 하루 전체를 가진 것처럼 캘린더를 만들었다(10/14 수: 앱=06-15 조형구·17-24 유원정 → 캘린더=00-15·17-24 조형구). GAS 의 공유 함수를 웹앱 본문으로 통일(추첨·직렬화·투표검증·유효스케줄 4개 교체, 분기 헬퍼 6개 추가), 캘린더에 결과 문서 전체를 넘기고, 봇이 결과를 만들 때 `quarterAssign` 포함(규칙 필수 필드), Slack 발표를 시간대별로 표기. 합성은 핵심 15개 함수가 이미 동일·실데이터 3주 불일치 0건이었고, '취소 기록 삭제 후 남은 예약' 엣지만 앱과 같은 우선순위로 맞춤.
- **10-07 모바일 특이사항 표 찌그러짐 수정**: 390px 에서 날짜·이름 값이 한 글자씩 세로로 쪼개짐(날짜 셀 폭 3px·18줄). 원인은 td 의 인라인 `width:1%`. 모바일 카드 CSS 에 `table.list td, th { width: auto !important }` 추가(두 앱 공통).
- **10-07 구글 캘린더 동기화 5일간 중단 → 복구 + 하트비트 경고 배너**: 원인은 GAS 프로젝트 2개가 Drive 휴지통에 들어간 것(10-02 이후 실행 0건). 휴지통에 꺼내 즉시 재가동. 재발 시 사람이 알아채도록, 봇이 `syncMeta/<app>_bot.okMs` 를 30분마다 갱신하고 웹앱이 60분 이상 낡으면 상단에 붉은 경고 배너를 띄운다(두 앱 공통). **임계값은 기록 간격의 2배** — 한 번 거르는 건 눈감아 주고 두 번 연속 놓치면 경고.
- **10-02 폴더 정리**.
- **09-29 구조 재설계 ③(초안 → 사용자 컨펌 → 배포)**: 단계 표시 한 줄, 탭 어휘 통일·이모지 제거(Optics ‘실시간 예약’ → ‘조율·채팅’), 앱 전환 메뉴·휴대폰 하단 탭(주요 4 + 더보기), Optics ‘지금 할 일’ 카드, Optics 휴대폰 요일별 목록 ↔ 표로 보기.
- **09-29 결함 A3**: 칸 팝업 ‘현재 배정’·기본 선택 = 현재 배정자, 남의 배정 변경 시 확인 + 조율 채팅 [자동 기록].
- **09-29 index 부제 삭제**(자명한 지시문 제거 원칙).
- **08-08 Firestore 읽기 한도 → 변경 감지 도입**, 07월 설계·확정 취소·캘린더 연동.

## 교훈 · 트러블슈팅
- **화면 번역은 앱 코드에 t() 를 박는 대신 'DOM 번역 층' 으로.** 600개 문구가 템플릿 리터럴 수백 곳에 흩어져 있어 코드를 고치면 로직 회귀 위험이 크다. 그려진 글자를 사전으로 바꾸면 앱 로직은 한 줄도 안 건드리고, KOR 은 기존과 바이트 단위로 같은 화면이 된다. 대신 (1) 사전 누락은 '영어 화면에 남은 한글 0' 전수 점검(국면×역할×탭×클릭)으로 잡고, (2) 한 글자 키(월·수·일…)는 일반 단어와 겹치므로('할 수 없' 의 수) 경계 규칙을 따로 두며, (3) 사용자 글·이름은 반드시 번역에서 빼야 한다.
- 공유 데이터(명단)를 다루는 UI 는 앱마다 반쪽씩 두지 말 것 — 한때 삭제는 합성에만, 광학 참여 전환은 광학에만 있어 관리자가 두 앱을 오가야 했다. 공용 블록을 두 앱에 동일하게 넣고 '블록 본문 동일' 을 확인한다.
- **같은 로직이 웹앱과 GAS 에 두 벌 있으면 반드시 어긋난다.** 시간대 투표를 웹앱에만 반영하고 GAS 는 옛 코어로 남아, 캘린더·봇 추첨·발표가 앱과 다른 결과를 냈다(봇 추첨은 시드부터 달랐음). GAS 의 공유 함수는 손으로 고치지 말고 **웹앱 본문을 그대로 복사**하고, 배포 전 '공유 함수 본문 diff = 0' 을 확인할 것.
- **인라인 스타일은 미디어쿼리를 이긴다.** 데스크톱 표에서 '내용폭에 맞춰 줄이기' 용도로 쓰는 `style="width:1%"` 가 모바일 카드 모드에서 셀을 3px 로 찌그러뜨린다. 카드 CSS 쪽에서 `width: auto !important` 로 되돌릴 것.
- **모바일 표 점검은 '가로 넘침'만으로 부족하다.** 3px 짜리 셀은 넘치지 않으므로 기존 테스트를 그대로 통과했다. **셀 폭 하한**(값폭 < 60px = 찌그러짐)도 함께 봐야 한다.
- **조용히 죽는 실패 모드를 설계에서 가정할 것.** 휴지통에 있는 GAS 스크립트는 Google 이 아예 호출하지 않아 실행 오류도 실패 알림 메일도 남지 않는다. 트리거는 '등록됨 · 오류율 0%' 로 멀쩡해 보였고, 캘린더만 5일간 조용히 낡았다. 에러 로그는 '돌다가 실패한 것'만 잡는다 — **살아있다는 신호(하트비트)를 따로 두어야** '아예 안 도는 것'을 잡는다.
- 하트비트 **임계값은 기록 간격에 바싹 붙이면 안 된다**(최소 2배). 간격과 같게 두면 정상 동작 중에도 기록 직전마다 배너가 깜빡인다.
- 봇 상태 조회는 실시간 구독이 아니라 주기적 단건 조회로. 배너는 실시간일 필요가 없고, 구독은 접속자 수만큼 읽기를 먹는다(읽기 한도로 앱 전체가 멈춘 이력 있음).
- Apps Script 좌측 메뉴의 `내 프로젝트`·`모든 프로젝트`·`휴지통` 이 모두 비어 보여도 프로젝트가 없는 게 아니다(소유자가 다른 계정이고 내 역할이 편집기면 그렇게 보인다). 프로젝트는 **`내 트리거` 행의 링크**로 들어가야 보인다.
- Firestore 무료 읽기 한도: 전체 재구독 대신 변경 감지.
- 남의 배정을 바꾸는 동작은 확인 + 자동 기록(조율 채팅)으로 흔적을 남긴다.
- 사용자가 ‘기존보다 나을지 모르겠다’고 한 재설계는 초안(전·후 이미지 + 데모 HTML)으로 먼저 컨펌받는다.
